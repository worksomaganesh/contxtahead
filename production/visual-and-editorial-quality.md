# Visual System, Editing Rules, and Editorial Quality

## 1. Identity: fully faceless

CONTXT AHEAD is a faceless publication, not a synthetic-presenter influencer account.

**Locked:**
- No human on-camera presenter.
- No realistic AI-human avatar as the channel's face.
- Voiceover-led narration.
- Editorial motion graphics, kinetic typography, data visualisation, timelines, diagrams, and screen recordings.

An abstract recurring visual motif or non-human graphic guide may be tested. It is optional; do not block production on it.

## 2. Visual language

Aim for a premium, calm, analytical, globally readable editorial style.

Core visual ingredients:
- Purposeful motion graphics.
- Typography integrated into the scene.
- Cinematic technology footage used as illustration, not evidence.
- Clean statistical charts generated from verified values.
- Timelines, maps, comparisons, ecosystem diagrams, and role/skill maps.
- Real screen recordings for sources and interfaces.
- Consistent source attribution and on-screen data labels.

Colour and typography proposals remain exploratory until tested in profile graphics, thumbnails, charts, and video frames. Keep the palette distinct from TECHENIGMASTUDIOS' fixed black/yellow identity.

## 3. Motion and layout rules

- Start with the question or visual tension; no long logo animation.
- Prefer continuous visual logic over disconnected slides.
- Use camera movement, scale, masking, and kinetic type only when they explain or emphasise the narrative.
- Keep text large enough for a phone screen.
- Use restrained transitions; avoid gratuitous effects and visual noise.
- Use consistent margins and safe areas across vertical and horizontal formats.
- Do not place critical text under platform interface overlays.
- Never use an image model to fabricate exact statistics, charts, UI evidence, logos, or screenshots.

## 4. Audio rules

- Creator-recorded voice is primary.
- Record in a quiet room with consistent mic distance.
- Prioritise clarity, natural pacing, and intelligibility.
- Remove obvious noise, plosives, harsh sibilance, and clipping.
- Music must support rather than compete with narration.
- Use sound effects sparingly and purposefully.
- Listen on headphones and ordinary phone speakers before approval.
- Verify rights and terms for music, effects, TTS, and voice assets.

## 5. Editing baseline

- 9:16 vertical for Shorts/Reels; prepare separate 16:9 composition for long-form.
- Captions are required for spoken content.
- Captions must be corrected manually; automatic transcription is not authoritative.
- Highlight only important words or statistics.
- Change the visual when the narrative changes, not at arbitrary intervals.
- Use actual figures from the source register.
- Attribute data on screen and in the description where appropriate.
- Avoid long text blocks that merely repeat the voiceover.
- Finish in DaVinci Resolve.
- Use Remotion or original HTML/SVG/GSAP for deterministic, reusable data-driven scenes when appropriate.

## 6. Visual evidence rules

Every chart or diagram must record:
- Data/source ID.
- Unit and geography.
- Period covered.
- Denominator/sample where applicable.
- Definition used.
- Any caveat or uncertainty.
- Date the data was accessed.

If a graphic simplifies a concept, label it as a conceptual illustration. Do not imply that generated B-roll depicts the actual event, company, person, or location unless it genuinely does.

## 7. Quality gates

Publication is blocked until all critical checks pass.

| Gate | Required checks |
|---|---|
| Audience | Specific audience and useful payoff |
| Brand | Fits CONTXT AHEAD, not a duplicate tutorial/demo |
| Evidence | Material claims mapped to reliable sources |
| Editorial | Hook is honest; fact, attribution, analysis, scenario separated |
| Visual | Charts accurate; imagery not misleading; text readable |
| Audio | Narration intelligible; no clipping; music balanced |
| Rights/privacy | Assets licensed/owned; private data hidden |
| Accessibility | Captions, contrast, readable labels |
| Technical | Correct aspect ratio, frame rate, codec, audio, file integrity |
| Human approval | Final human review recorded |

## 8. AI transparency and platform requirements

- Label or disclose realistic synthetic/altered content when required by the platform.
- Do not present generated scenes as real documentary footage.
- Do not clone a public figure, creator, or other person's voice.
- Do not use unlicensed music, footage, photographs, or creator assets.
- Re-check YouTube, Instagram, and LinkedIn rules before publication because platform policies change.

## 9. Corrections policy

If a material error is found:
1. Verify against the original evidence.
2. Correct the description or video where possible.
3. Add a correction note when the error could affect audience understanding.
4. Update the claim register and research pack.
5. Record date, change, and reason.
6. Review whether any derivative post must also be corrected.

Keep the original decision and correction history. Do not silently erase material errors.
